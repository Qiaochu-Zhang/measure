# V1_20：PSD 为什么是折线、为什么频点有限，以及怎样观察 wiggling

## 1. 先回答频点数量的问题

根据本仓库 V1_19 实际代码，默认 PSD 已经沿 trench **每个像素行取一个边缘点**。图像不是被绘图程序任意抽掉大部分点；横坐标也没有另设一个很小的“绘图点数”。主要限制是：**连续有效边缘的长度有限，傅里叶变换只能给出对应数量的独立频点**。

V1_19 的 `cdsem_psd.segment_spectra()` 对每个连续有效段调用 SciPy `signal.periodogram()`，没有指定 nfft，因此 FFT 长度就是该段实际点数 N。绘图调用 `loglog()` 连接这些离散频点，所以呈现折线。它不是文章中经过模型拟合后的平滑曲线。

旧版本的两个引擎原本已在 `PSD/V10/`、`PSD/V13/` 分别输出，但每张图有 left/right/width/center 四个子图，每个子图叠加不同结构、normal/unrotated 和连续段。V1_20 将展示方式固定为每引擎一张单面板图，每张只展示整图 LER、LWR 两条曲线。

## 2. 空间采样和频率采样分别是什么

设旋转后沿拟合平均中心线的采样间距为 Δs，连续有效段有 N 个空间采样点：

```text
Δs = Δy_px × pixel_size_nm / |cos(θ)|
f_k = k / (N × Δs), k = 0, 1, …, floor(N/2)
Δf = 1 / (N × Δs)
单边谱总频点数 = floor(N/2) + 1（含 DC）
正频率点数 = floor(N/2)（不含 DC）
f_max = floor(N/2) / (N × Δs)
Nyquist 上限 = 1 / (2 × Δs)（偶数 N 时恰好取到）
```

θ 是该结构拟合中心线相对竖直方向的夹角，Δy 是原图采样行间隔。这里的 `N×Δs` 是 DFT 的记录周期；首末点几何跨度是 `(N−1)×Δs`，两者不要混淆。

| 连续空间点 N | 单边 FFT 频点（含 DC） | 可画的正频率点（最多） |
|---:|---:|---:|
| 16 | 9 | 8 |
| 64 | 33 | 32 |
| 128 | 65 | 64 |
| 360 | 181 | 180 |
| 512 | 257 | 256 |

例如 N=360、像素尺寸 1.3181 nm/px、θ≈0 时，Δs≈1.3181 nm，Δf≈0.0021074 nm⁻¹，最大频率≈0.379334 nm⁻¹。若低频上限是 0.01 nm⁻¹，只有 k=1、2、3、4 四个独立正频率点落在 LF 中。这正是“低频部分看起来只有少量折线点”的常见原因，并不意味着整条边缘只取了四个点。

频率点在线性频率轴等间距，在对数横坐标上低频点显得稀疏、高频点显得密集。旧图还会排除 f=0 和 PSD≤0 的点，因为对数坐标不能显示它们；新版对非正 PSD 使用断开的空值显示，不伪造正数。

## 3. V1_19 实际取了多少边缘点

默认主测量和 PSD 使用两套采样：

- **主 CD/LER/LWR**：默认 128 个采样位置、32 行灰度平均、3px 横向平滑；主 LWR 默认 group4。这些设置不能直接当成 PSD 点数。
- **默认 `--psd-edge-source single-row`**：PSD 单独重提 V10/V13 边缘，强制 average-range=1、smoothing-pixel=1、integer_sampling=True、sample_number=extend_length_px，通常在所选测量范围内每行一次。默认测量长度至多 360px，也可能因 ROI、average-range 与端部裁剪更短。
- **`--psd-edge-source measurement`**：复用主测量的采样槽和已平均的灰度配方；这时默认 N 的上限通常是 128，理论正频点最多 64，且平均会抑制部分高频信息。

这三种因素还会进一步减少点数：边缘未检出、背景/端部被排除、默认不允许合成补点参与 PSD。程序不能把不连续位置拼接成连续边缘，而是在缺口处分段。例如 360 个槽位被缺口分成几个短段，任何一个段的 FFT 点数都小于完整 360 点的情况。小于 psd-min-segment（默认 16）的段会跳过。

旧参数 psd-nperseg 默认 64 是遗留 Welch 接口值，**本版本 periodogram 实际不使用它**；显式传入会被拒绝。不能据此推断旧图仅使用了 64 点 FFT。

没有用户真实图片或其结果 CSV，因此不能声称你某张旧图确切用了 N 个点。应查看原生 `per_structure_psd_summary.csv` 的 input_slots、input_valid_count、used_slots、frequency_step_per_nm、span_nm；V1_20 新增 `image_psd_summary.csv` 和逐频点支持数，便于直接核查。

## 4. V1_20 怎样把同图全部 trench 综合为两条谱

每个图片、每个引擎独立执行：

1. 使用 ROI 内全部通过原稳定性筛选的 trench，不只使用主表 max-number 选中的几条。默认重新提取单行边缘；measurement 模式复用全部合格主来源。
2. 对每条 trench 使用自己的拟合中心线做旋转法向坐标变换。只计算 normal 轴 PSD；没有 unrotated PSD。
3. 保留成对有效性掩码，按每个连续有效段计算左右边缘、宽度和中心线的原生功率谱。
4. 每段先得到 `P_LER=(P_left+P_right)/2`、`P_LWR=P_(right−left)`；再以 `N×Δs` 为长度权重，对同图同引擎的段谱平均。左右边缘等权。较长的真实可用记录提供更大权重；不是把所有 trench 的幅值相加。
5. 绘制两条综合谱：LER 红色、LWR 蓝色。V10、V13 各一张，不平均到一起；不同图片也不平均。

**为什么不先平均边缘坐标再 FFT？** 不同 trench 的摆动相位可能相反，先平均坐标会抵消真实摆动。先计算各自功率再平均，才能保留图像内总体起伏强度。直接首尾拼接各条 trench 则会引入边界跳跃和虚假长波，同样不采用。

不同段长和旋转角会产生不同频率网格。V1_20 用物理记录周期最长段的正频率网格作为绘图坐标，在每个段自身 `[Δf_native, f_max_native]` 范围内对功率密度线性对齐，再按该频点真正有支持的段加权。短段不会被外推到它无法分辨的低频。CSV 记录每个频点的贡献段数、结构数、权重及最好/最差原生频率分辨率。

这种对齐只为合并频率坐标，不增加独立信息；不做零填充，不凭空增加真正的低频观测，也不实施额外的曲线平滑。多个结构可以降低谱估计的起伏，但不会让一条 360px 边缘具有 3600px 的低频分辨率。不同频点可能由不同结构集合贡献，比较低频时必须查看支持数。

频带数值单独在各段**原生正频率点**上积分 `ΣP×Δf_native`，再按该频带有支持段的长度加权，不以插值后的绘图点数作为积分依据。频带缺少任何原生频点时状态为 NO_FREQUENCY_SUPPORT，数值留空；不能解释成该频带没有 roughness。各频带的支持集合不一定相同，不能机械要求三个分带均值相加等于另一种支持定义的全谱均值。

## 5. 怎样借鉴文章思想观察 wiggling

引用文章为 Libin Zhang 等，2017 CSTIC，DOI：[10.1109/CSTIC.2017.7919761](https://doi.org/10.1109/CSTIC.2017.7919761)。公开摘要说明它使用 PSD 比较 LER/LWR，并用 Palasantzas 函数拟合；课题组公开说明展示了 LER、LWR 同图对照和 LF/MF/HF 分区，指出明显 wiggling 的中低频 LER 可高于 LWR。

公开资料来源：

- [论文公开摘要及 DOI（ResearchGate）](https://www.researchgate.net/publication/317054233_An_offline_roughness_evaluation_software_and_its_application_in_quantitative_calculation_of_wiggling_based_on_low_frequency_Power_Spectral_Density_method)
- [课题组《离线式线条粗糙度分析软件及应用》](https://m.chipmanufacturing.org/nd.jsp?id=331&mid=5)
- [SciPy periodogram 官方定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)

本次无法获取论文公开全文，不能确认其全部公式、拟合细节或实验频段分界。V1_20 实现的是“同图对照 LER/LWR、中低频分区观察”的思想，没有声称完整复现原文算法，也没有实现 Palasantzas 拟合或论文专属 wiggling 判定阈值。

从边缘信号本身可推导：令 L、R 为旋转后左右边缘位置，W=R−L，C=(L+R)/2。只要使用相同配对段、窗函数及线性去趋势算子，就有：

```text
P_LER = (P_L + P_R)/2
P_LWR = P_L + P_R − 2 Re(S_LR)
P_center = P_LER − P_LWR/4
归一化边缘相关性 = 1 − P_LWR/(2 P_LER)  （P_LER>0）
```

这是本版本的信号恒等关系与辅助指标定义，不是宣称采用了原论文某个 wiggling factor 公式。频带表中的 edge_correlation_from_psd 在同样定义的频带方差上计算这个比值。

- 两边**同向共同摆动**时，LER 和 center 的低频功率增大，而宽度变化可能很小、LWR 较低；相关性趋向 +1。
- 两边**反向改变宽度**时，LWR 会明显增大，center 功率较小；相关性可能为负。
- 两边粗糙度彼此不相关时，期望 `P_LWR≈2P_LER`，相关性接近 0；单次有限样本会有波动。

因此应同时看低频/中频的两条谱、频带积分、center 方差、实际边缘图和支持长度；不能只凭某一个折线点认定 wiggling。这里测的是所选 trench 或 line 的二维俯视边缘，不直接证明三维应力扭曲的工艺机理。LER=两边功率均值，和“只用左边缘的 LER”或“先平均两条边缘坐标”均不同。

PSD 仍包含 SEM 噪声，没有噪声去偏。也没有将平均谱强制拟合成一条平滑线。主表 LWR 经过 group4，而 PSD LWR 没有，不应要求其积分 3σ 与主表完全相等。

## 6. LF / MF / HF 的竖线怎么定义

默认采用以下**可修改的分析配方**：

| 频段 | 空间频率 nm⁻¹ | 对应波长 |
|---|---|---|
| LF | 0<f≤0.01 | λ≥100nm |
| MF | 0.01<f≤0.05 | 20nm≤λ<100nm |
| HF | f>0.05 | λ<20nm |

三段用两个边界分开，所以画两条竖直虚线，并在顶部标 LF、MF、HF。100nm 沿用旧版 split-wavelength 的数值，20nm 是新增的暂定中/高频分界。**它们不是普遍物理常数，也不是已经核实的论文阈值**。可通过以下参数修改，必须满足 `0<高频分界波长<低频分界波长`：

```bash
--psd-split-wavelength 100 --psd-high-split-wavelength 20
```

图上的配方虚线可以落在本图片测不到的频率范围；这不意味着那里有数据，空白范围不会外推谱线。无频带支持时表中留空。

## 7. 真正想让低频更可信，该改什么

优先增加**连续有效边缘的物理观察长度**：合适的视场、沿线 extend-length、正确 ROI、准确定位与稳定提边缘。更长记录才会降低 Δf，让低频具有更多独立观测；同时应保证仍在有效 trench 内。多个同类 trench 的功率平均可降低估计方差，但不能替代足够长的单段记录。

默认 single-row 已经每行采样。把 sample-number 改得很大不会让默认 PSD 自动更密；它控制主测量。measurement 模式中加密采样也不能创造超出原图像素和灰度平均窗口的独立信息。降低 psd-min-segment 只能允许更多短段进入，反而会引入频率分辨率更差的来源；背景插值或大量合成补点也不能当作真实观测。

V1_20 默认在旋转后仅去均值（constant），减少逐段 linear 去趋势对低频的额外抑制。可显式选择 linear 作对照。旋转拟合本身仍去除全局倾斜，有限段长、Hann 窗及配方仍会影响最低几个频点；本版本不承诺无偏恢复接近/超过视场长度的摆动。

如需一条更平滑的论文风格曲线，应另做注明模型与拟合范围的拟合，并保留原始 PSD 点、误差与拟合质量。单纯增加绘图插值点或零填充，只会让线更密，不会提高物理分辨率。本次没有为了外观生成额外频点。

## 8. 输出位置与验证

每张图正常启用 PSD 和统计绘图时固定输出：

```text
PSD/V10/<相对路径>/<原完整文件名>.psd.png
PSD/V13/<相对路径>/<原完整文件名>.psd.png
```

没有可用连续段时输出写明原因的占位图，不能把它作为有效测量。显式 skip-psd 关闭所有 PSD，skip-statistics-plots 关闭统计图但保留 PSD 数值。

新自检使用已知 512 点低频正弦波确认 256 个正频点、已知方差、同相/反相边缘、反相的不同 trench 仍保留功率、缺失频带留空、背景不跨越、旋转后间距、两引擎隔离、两条曲线及两条虚线。真实编码的两张同名 TIFF/PNG 集成场景验证恰好 4 张 PSD 图，并验证主表 max-number=1 时 PSD 仍使用全部合格结构。

完整自检及 V1_19 数值/文件保留对照分别见包内 validation_report.json、仓库 audits/v1_20_release_evidence.json。examples/input_wiggling 是可复现合成图，并非用户实际 SEM 数据。实际图像的边缘定位质量和 wiggling 表现仍应在应用时核查。
