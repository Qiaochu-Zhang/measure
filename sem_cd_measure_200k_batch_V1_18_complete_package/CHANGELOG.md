# V1_18 修改记录

## 2026-09-22：trench 先全测、再筛选

基于 V1_17（`2301b35`）创建独立 V1_18 目录、主入口、启动器、依赖清单、文档、自检报告和 ZIP。V1_15、V1_16、V1_17 保持原样。

- trench 使用与 line 来源相同的全候选搜索路径：严格排除非真实 trench 的候选，不提前按 max-number 截断。
- 先对全部合规候选运行原 V10/V13 逐点测量，再按原 stable 条件筛选。最后仅从合格集合按原中心/左右及可选间距先验选取 max-number 条 trench。
- 最终选择沿用实际定位模式的邻居间隔，bright-line 取相邻沟槽；保留显式 space-reference 的原排序先验。
- 保留阈值、跟踪、Viterbi/ERF、continuity、飞点、旋转、CD/LER/LWR、分组和 PSD 数学。line 共享边算法保持 V1_17 原样。
- 数量不足时保留合格部分；不再使用不合格 trench 填满数量或参加旧式汇总。全部不合格时输出缺失状态，保留审计。
- 独立单行 PSD 同样先全测再筛选，频谱计算方式不变。pitch 复用全部已测合格来源，保留相邻检查、合成/背景排除、按 max-number 等权平均、只输出旋转值和 Excel 末列位置。
- 新增 trench_selection、trench_source_samples；主采样表增加 trench_source_id。定位表增加来源是否已测/合格，selected 指向最终入选。
- 新增全量扫描、假中心排除、中心不合格后改选、数量不足/为零、单 trench、双模式同来源逐点一致、可选拟合/非对称阈值和 PSD 测试。

旧无 ROI / legacy 配方中的部分 V13 trench 仅约 33%–35% 有效点，低于原 70% 门槛，V1_17 仍可用回退逻辑汇总。V1_18 按新要求排除这些对象。已逐点对照确认其原始坐标、阈值和有效性未变；自检检查旧边缘值保留及新的筛除行为，不以旧的不合格对象均值作为新汇总目标。

完整自检的 60 个集成场景全部通过（含本次新增 12 个场景），详见 validation_report.json；仓库 audits/v1_18_release_evidence.json 记录原版本保留、line 数值一致、trench 原始边缘与筛选变化，以及独立 ZIP 验证。测试使用合成图，尚无用户实际失败 SEM 图用于核对。
