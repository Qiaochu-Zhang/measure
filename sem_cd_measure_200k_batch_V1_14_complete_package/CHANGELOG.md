# V1_14 变更记录

基线：measure 仓库 `05c1ecf` 所含 V13_modified 原包；本次新增独立 V1_14 包，旧 ZIP 和旧源码目录未改动。

## 修复

- 阈值交点搜索允许位于所选梯度峰两侧，但限于原锚点搜索窗和正确的左右区域；继续执行原拓扑/宽度/跳变检查。
- 单点 LER、单组 LWR 不再显示为 0。单个机台对照点的标准差和 Bland–Altman 一致性界限也不再伪造为 0。
- 8bit 输入不拉伸动态范围；空白图片由背景策略正常跳过。
- 一张图片只保留一条图像级记录；单引擎失败保留另一引擎指标。
- 机台表无匹配、缺失或损坏，及 PSD 附属导出失败不阻止主 CSV 和可完成的主 Excel 导出。
- 损坏 PNG 保留在错误汇总中；旧输出目录不作为新的输入继续处理。
- 默认拒绝向非空目录输出，避免同版本覆盖和遗留文件混淆。

## 新增与明确改变

- 默认自动背景排除、ROI 图、原图坐标诊断、逐点背景标志；手动 ROI/关闭开关保留。
- 总结表按文件名、status、method 开头，mixed/V13/V10 顺序；完整宽表同时保留。
- PSD 默认单行、整数像素等间隔重新提边缘；也可显式复用主配方边缘。
- PSD 只生成未分组、未平均的逐结构/逐连续段 periodogram；V10/V13 分别输出。原版平均谱按需求移除，不再将 group4 LWR 当作 PSD 的主宽度信号。
- 背景不参与连续性填补，也不允许 PSD 插值跨过背景缺口。
- 默认仅 OK 进入条件汇总/机台比较；REVIEW 可显式重新纳入。
- 主指标的 32 行平均、group4 LWR 等默认定义保留，未擅自改成 noise-unbiased 粗糙度。

## 精简与兼容

- 17 个运行源码文件整合为 7 个；去掉未调用的历史 V1_7/V5/V7/V8/V9/V10 入口、重复边缘引擎和独立候选选择脚本。
- 保留 V13_modified 暴露的 trench/line、双坐标、三方法、诊断、Viterbi/ERF、连续性、flyer、机台对照及统计图等主功能。via 不属于 V13_modified 的入口能力，未加入。
- `--no-auto-roi --threshold-search legacy` 可对随包 8bit 示例复现旧 mixed 结果；这不是承诺所有输入完全一致，因为统计边界错误和 8bit 归一化已明确修正。
- 新表格和 PSD 文件结构请按 README 读取，不再依赖旧列位置或旧平均谱文件名。

## 验证边界

完整自动自检及一次含标注、机台统计图、诊断图、双引擎 PSD 图的示例运行已作为发布检查。详见 `validation_report.json` 与仓库发布说明。没有真实 SEM 精度认证，没有商业量测软件实测对标，没有把低噪声或短线条误删概率验证到工艺验收级别。
