**第 2 页｜科研工作里，哪些重复操作最耗时间**

- 每次实验都要打开许多 CSV/Excel，复制、拼表、改列名。
- 不同仪器的单位和样品编号不一致，容易错配。
- 反复计算平均值、标准差，修改同一类图，整理同一份周报。
- 上次做过的分析，这次仍然需要重走一遍。

画面：人工操作链与“换数据、复用流程”的对照。互动：请听众在心里选一个每周都会重复的数据任务。

**第 5 页｜为什么先把 AI 用在编程和数据处理上**

- 输入已在电脑里：表格、文件、图像、仪器导出数据。
- 处理步骤容易描述：读取、合并、换算、统计、作图。
- 结果有核对入口：原始记录、手算样例、已有软件或标定样本。
- 同类工作可以重复，首次调试的投入能在后续批次复用。

页面落点：优先选择“重复出现、规则明确、数据可获得、结果可检查”的任务。代码运行成功只是技术检查，科学口径仍需人确定。

**第 6 页｜AI只需理解到这一步：能帮助读、写、整理和调用工具**

- 阅读：提炼论文方法、解释数据字段和报错。
- 编写：形成代码、报告和分析方案初稿。
- 执行：接入工具后，可读取文件、运行程序并根据反馈修改。
- 专业判断：实验意义、统计方法与结论由研究人员核对。

**第 7 页｜代码是什么：把实验处理步骤写成电脑能执行的 SOP**

- 人的要求：“把所有实验文件合并，按实验条件统计，输出 Excel 和图。”
- 程序的步骤：找文件 → 读数据 → 核对字段和单位 → 计算 → 导出。
- Python 是实现这类流程的一种编程语言。

讲者重点：第一次让 AI 协助写和调试；方法固定以后，同一脚本可以用于下一批数据。能否复用取决于新数据是否满足原来的格式和规则。

来源：A6—10。

**第 9 页｜Excel 和 Python 怎样分工**

- Excel：适合检查样例、查看明细、临时筛选和交流结果。
- Python：适合跨文件合并、重复计算和按固定规范导出。
- 常见组合：Excel/CSV 输入 → Python 批处理 → Excel/图片输出。
- AI帮助编写和维护程序；固定脚本的日常运行可以不调用 AI。

说明：这里指普通 Python 读写 `.xlsx` 文件，不要求使用 Excel 内置的 Python 功能，也不必让 AI 模拟鼠标逐格点击。

来源：A8、A22。

**第 12 页｜第一次使用：准备文件夹，先看方案，再试跑**

1. 使用单位允许的模型服务和工具入口，提前完成 Python 环境准备。
2. 建立练习目录，放入 2—3 个脱敏样例和一份字段说明。
3. 在该目录启动 OpenCode；先让它列出文件结构、拟用规则和不明确之处。
4. 用 Plan 做分析，再切换到 Build 实施；具体操作按安装版本界面。
5. 在新的输出目录查看结果，抽样核对后再处理完整批次。

Plan 与 Build 是官方提供的两种主要工作模式，具体文件和命令访问仍受权限配置影响。[OpenCode Agents](https://opencode.ai/docs/agents/)

**第 13 页｜非程序员最重要的能力：把任务说成一张实验处理单**

一份任务至少说明五件事：

- 输入：文件在哪、什么格式、字段与单位是什么。
- 目标：想回答什么实验问题。
- 规则：怎样合并、分组、换算和对待异常。
- 输出：Excel 工作表、图片和文件名。
- 验收：用哪些样例核对，什么情况应该停下来询问。

对比示例：“分析一下数据” → “合并 raw 文件夹的 CSV，按批次和实验条件统计，输出原始明细、样品级结果和异常清单；遇到未知单位先报告。”

来源：A12、B21。

**第 14 页｜本次主线：AI → Skill → Python → Excel → 人工验收**

```mermaid
flowchart LR
    U[科研人员定义任务] --> A[AI / OpenCode组织执行]
    S[Skill：规则、模板、脚本] --> A
    D[原始 CSV / Excel / 图像] --> P[Python处理和计算]
    A --> P
    P --> E[Excel、图表、日志]
    E --> V[人工核对与科研解释]
    V -->|修正规则并确认| S
```

逐项说明：人定义问题；AI组织步骤；Skill提供方法；Python执行；Excel呈现；人验收。

教学中可以用“AI → Skill → Python → Excel”记忆，但实际是 Agent 读取 Skill 并调用 Python。Skill并非每个任务都必需，单次任务可以先跑通，反复使用后再封装。

来源：新增核心页，连接 A10、A13 和 B21。

**第 15 页｜Skill是什么：把实验室的处理经验整理成可调用的方法包**

- 普通提示词交代这一次要做什么。
- Skill保存这一类任务通常怎么做、依据什么规则、输出什么、如何检查。
- 它可包含说明文件，以及需要时使用的脚本、字段规范和报告模板。
- 加载 Skill 不会重新训练模型，也不会自动保证结果正确。

类比：新同事拿到实验室的数据处理 SOP、示例和工具。概念依据 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。本案例的具体规范是为本次分享设计的教学建议。
