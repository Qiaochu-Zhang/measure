**第 7 页｜代码是什么：把实验处理步骤写成电脑能执行的 SOP**

- 人的要求：“把所有实验文件合并，按实验条件统计，输出 Excel 和图。”
- 程序的步骤：找文件 → 读数据 → 核对字段和单位 → 计算 → 导出。
- Python 是实现这类流程的一种编程语言。

讲者重点：第一次让 AI 协助写和调试；方法固定以后，同一脚本可以用于下一批数据。能否复用取决于新数据是否满足原来的格式和规则。

**第 9 页｜Excel 和 Python 怎样分工**

- Excel：适合检查样例、查看明细、临时筛选和交流结果。
- Python：适合跨文件合并、重复计算和按固定规范导出。
- 常见组合：Excel/CSV 输入 → Python 批处理 → Excel/图片输出。
- AI帮助编写和维护程序；固定脚本的日常运行可以不调用 AI。

说明：这里指普通 Python 读写 `.xlsx` 文件，不要求使用 Excel 内置的 Python 功能，也不必让 AI 模拟鼠标逐格点击。

**第 12 页｜第一次使用：准备文件夹，先看方案，再试跑**

**第 13 页｜非程序员最重要的能力：把任务说成一张实验处理单**

一份任务至少说明五件事：

- 输入：文件在哪、什么格式、字段与单位是什么。
- 目标：想回答什么实验问题。
- 规则：怎样合并、分组、换算和对待异常。
- 输出：Excel 工作表、图片和文件名。
- 验收：用哪些样例核对，什么情况应该停下来询问。

对比示例：“分析一下数据” → “合并 raw 文件夹的 CSV，按批次和实验条件统计，输出原始明细、样品级结果和异常清单；遇到未知单位先报告。”

**第 15 页｜Skill是什么：把实验室的处理经验整理成可调用的方法包**

- 普通提示词交代这一次要做什么。
- Skill保存这一类任务通常怎么做、依据什么规则、输出什么、如何检查。
- 它可包含说明文件，以及需要时使用的脚本、字段规范和报告模板。
- 加载 Skill 不会重新训练模型，也不会自动保证结果正确。

类比：新同事拿到实验室的数据处理 SOP、示例和工具。概念依据 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。本案例的具体规范是为本次分享设计的教学建议。

**第 16 页｜一个科研数据 Skill 应该写什么**

用“实验数据汇总”示例卡，内容以中文呈现：

| 项目 | 具体例子 |
|---|---|
| 适用任务 | 合并同类仪器导出的实验 CSV，按已确认口径汇总 |
| 输入要求 | 样品编号、批次、条件、测量值、单位和重复编号 |
| 处理规则 | 编号按文本保留；单位按字段说明换算；未知单位报告 |
| 异常规则 | 缺失、重复和疑似离群保留记录，不自动改成零或删除 |
| 输出规范 | 明细、样品级统计、条件汇总、异常、方法与来源 |
| 验收要求 | 文件数、行数、单位、样品数及手算样例核对 |

讲者强调：同事提供自己熟悉的实验规则，再由 AI 协助整理成规范；其中的科学判断需要负责人审定。

**第 17 页｜Skill怎么用，怎样让下次少解释**

- 初次：在小样本上把规则和脚本调通。
- 固化：把确认的方法、脚本入口、样例和验收要求存入 Skill。
- 复用：“使用实验数据汇总 Skill，处理这次的新批次，先检查输入格式。”
- 更新：仪器导出格式或实验方法改变后，修改规范，重新用样例验收。

讲者备注：OpenCode 可从项目中的 `.opencode/skills/<名称>/SKILL.md` 发现技能；在任务中明确点名，并检查它是否加载了相应说明。目录说明参考 [OpenCode Skills 文档](https://opencode.ai/docs/skills/)。

复用同一脚本和方法有助于一致性；若每次重新生成程序，仍需版本核对，不能宣称结果天然可复现。

**第 18 页｜连续案例：20个实验文件，整理成一份可核对的报告**

教学设定：不同批次在若干固定温度条件下测量电阻，每个独立样品有多次技术重复。20 个文件只是演示规模。

- 原始字段：`sample_id`、`batch`、`condition`、`replicate_id`、`resistance`、`unit`。
- 故意设置几类常见问题：`001` 这样的样品编号、`ohm/kohm` 混用、空白值、重复导出的记录。
- 希望得到：干净的明细、样品级统计、条件级汇总、图表和异常清单。
- 展示输入与预期输出，让听众先看清目标。

来源：扩展 A13 的样品编号—温度—电阻案例。

**第 19 页｜计算之前，先确认数据口径**

- 同一个样品跨文件出现，是重复导出、技术重复，还是不同实验条件？
- 样品编号是否只在批次内唯一？分组键需包含什么字段？
- 技术重复先汇总到样品层，再按独立样品统计组间差异；如果研究设计不同，需要调整。
- 空白并非零，离群点并非错误；按照预先约定的方法处理并保留记录。
- 标准差描述哪一层的变化，图上的误差线表示 SD、SEM 还是置信区间？

本教学案例固定口径：先按“批次＋条件＋样品”求技术重复均值；再按“批次＋条件”对独立样品均值计算 mean、样本 SD 和 n。单个独立样品的组不输出假的 SD=0。

本页的统计规则是案例约定，应由实际实验设计决定。连接、去重和统计前先确认键，避免误将不同样品或实验条件拼在一起。

**第 20 页｜让 AI 先用三个文件试跑**

- 给出字段说明和目标，让 AI 先列出理解与不确定之处。
- 查看它提出的合并、单位换算、缺失和分组规则。
- 按已确认规则生成 Python，读取三个样例，输出到 `outputs/pilot/`。
- 检查编号、单位和一组手算结果；运行报错时，将完整错误和文件上下文交回 AI。

画面：自然语言任务、执行过程、试跑结果三个窗口。讲者提示：“程序能运行”与“科研口径正确”是两层不同的验收。

**第 21 页｜批量处理后，Excel应该让人查得清楚**

| 工作表 | 听众看到的内容 |
|---|---|
| `raw_index` | 输入文件、行数、读取状态 |
| `cleaned_data` | 保留来源的标准化明细，含原值、原单位和换算后值 |
| `sample_summary` | 每个样品的技术重复数、有效数和均值 |
| `condition_summary` | 每个批次/条件下的独立样品 n、均值和 SD |
| `issues` | 无效单位、缺失、重复或读取失败及处理状态 |
| `methods` | 分组、换算、缺失处理、误差线口径与脚本版本 |

讲解重点：得到一个能回查来源的结果包。没有进入统计的数据也需要能找到及解释。

**可直接用于第 20 页的完整示例提示词**

下面是教学用模板，字段、分组和统计规则需按实际实验修改。

```text
我需要把多批实验的电阻测量数据整理成可复核的 Excel 报告。

输入：
raw/ 下的 CSV 文件。字段为 sample_id、batch、condition、
replicate_id、resistance、unit。编号必须按文本读取，保留前导零。
字段说明见 data_dictionary.md。

实验结构：
同一“批次＋条件＋样品”有多次技术重复；独立样品才是组间统计单位。

规则：
1. 保留来源文件和原始行号；同时保留原始值与原始单位。
2. 按字段说明将 ohm、kohm 换算为 ohm；未知单位先报告，不猜测。
3. 缺失值不填零；无效数值记录原因并与有效数据区分。
4. 重复键先列入异常清单，不静默删除，不将重复导出当成独立样品。
5. 离群值只标记，不为得到更好看的趋势自动删除。
6. 先计算每个样品的有效技术重复均值；再按批次和条件计算独立样品
   均值的 mean、样本 SD（分母 n-1）和有效样品数 n。
   n 小于 2 时 SD 留空并说明；不存在有效值时不生成假零值。
7. 不覆盖 raw/，所有结果写入新的输出目录。

输出：
summary.xlsx：raw_index、cleaned_data、sample_summary、
condition_summary、issues、methods 六张表。
趋势图显示独立样品点、均值和 SD，标明单位与 n，并保存 PNG 和 SVG。
同时保留 Python 脚本、依赖说明、运行命令、参数和日志。

先做的工作：
请只读取目录和三个样例文件，列出你理解的字段、处理步骤和待确认事项。
本阶段先不批量处理。遇到数据含义不明确的地方，请指出具体文件、字段和示例。
规则确认后，先试跑三个文件，再给出一组可用 Excel 手工核对的结果。
```

示范复用指令：“使用已确认的实验数据汇总 Skill，先检查新批次的列名和单位是否兼容，再运行已保存脚本，输出到本次独立目录，并报告与旧批次格式的差异。”
