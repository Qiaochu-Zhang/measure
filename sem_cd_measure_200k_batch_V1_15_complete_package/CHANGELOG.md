# V1_15 变更记录

基线：仓库 main 的 V1_14（代码 e2c4607，完整参数手册 5a1bbb6）。新建独立 V1_15 包，不依赖旧目录。

1. 在原有背景筛选后加入 Y 端部裁剪，默认每端 1/20 平均长度。只采用前景列跨度均值这一种粗估计；记录长度、裁剪量和裁前/裁后原图边界。主测量完整平均窗口、continuity 及单行 PSD 共用有效掩码。
2. dark-line 保留原盆地识别、亮度筛选及周期关系。bright-line 使用两类自适应亮暗阈值和多数/均匀像素判据，把相邻真实 trench 作为相邻周期。代表轮廓和沿 Y 验证复用原算法。
3. auto 在整个有效区域判断交替深浅/宽窄暗谷的周期特征；每图只决定一次，双引擎及 PSD 共用。line 中央的真实灰度纳入定位上下文，不用被截掉的端部或外部背景参与定位。无足够交替证据默认 bright-line。
4. 新增 locator_summary、locator_candidates 导出，终端显示模式和每端裁剪量；非 compact 逐点表补充完整平均窗口范围。自动扫描排除 V1_14 和 V1_15 历史输出。
5. 原有边缘阈值、跟踪、Viterbi/ERF、continuity、flyer、CD/LER/LWR、双引擎 PSD、机台比较、图片导出和非空目录保护保留。关闭新掩码并用 dark-line 可做旧配方数值回归。
6. 新增两类合成示例、自检覆盖、全部 86 个 CLI 选项说明和独立 ZIP 校验清单。实际测试结果及依赖版本见 validation_report.json。

这是灰度/几何规则的工程改进。auto 不能从完全相同的灰度周期唯一推断物理身份，也不是语义背景分割或 SEM 计量认证。详见 RUN_GUIDE.md 第 11 节。
